🏢 4. CRM Automated Workflow Endpoints

These endpoints accept simplified JSON parameters and automatically map them to the corresponding Meta-approved template components.

POST /api/v1/crm/repair-booking-confirmed Template: repair_booking_confirmed

Dispatches an instant booking confirmation to the customer with their unique Job ID and estimated turnaround time.

Field Type Status Description
phone string Required 10-digit number or with 91 country code (e.g. 919342400879)
customerName string Required Customer's first or full name (e.g. Murali)
jobId string Required Job/Ticket ID (e.g. REP-1024)
device string Required Device name (e.g. Apple iPhone 13)
service string Required Service name (e.g. Screen Replacement)
turnaround string Optional Turnaround time (defaults to Same Day) 
{
  "phone": "919342400879",
  "customerName": "Murali",
  "jobId": "REP-1024",
  "device": "Apple iPhone 13",
  "service": "Screen Replacement",
  "turnaround": "Same Day (60 mins)"
}
POST /api/v1/crm/repair-status-update Template: repair_status_update

Notifies the customer whenever the repair changes status (e.g., In Diagnosis, Waiting for Spare Parts, Testing).

📨 5. Universal Messaging API

Use these endpoints to dispatch any registered Meta template dynamically or send direct messages within the 24-hour service session.

POST /api/v1/messages/send-template

Triggers any approved Meta template using positional body variables array ({{1}}, {{2}}, etc.):

{
  "to": "919342400879",
  "templateName": "repair_booking_confirmed",
  "languageCode": "en_US",
  "bodyVariables": [
    "Murali",
    "REP-1024",
    "Apple iPhone 13",
    "Screen Replacement",
    "Same Day"
  ]
}
POST /api/v1/messages/send-text

Sends direct text message to an active customer (must have messaged in the last 24 hours):

{
  "to": "919342400879",
  "text": "Hello Murali, your phone has passed all quality checks. You can visit our store to collect it!"
}

⚠️ 9. HTTP Error Codes & Troubleshooting

Status Meaning Troubleshooting Action
400 Bad Request Missing parameters Verify required fields (e.g., phone, customerName, jobId).
401 Unauthorized Invalid API Key Ensure x-api-key header matches itech_live_sec_7f9984e1b9384e9d9a1f.
404 Not Found Resource Not Found Verify URL endpoint path and format.
429 Rate Limit Too many requests Implement exponential backoff. Meta limits default to 80 msg/sec.
500 Meta Error Meta Graph API failure Check response body for Meta subcode (e.g., template not found or phone number invalid).
